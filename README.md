# Sense6 Ai Desktop — downloads

**Sense6 Ai Desktop** is an AI assistant that lives on your computer: it sees what you see, remembers what matters, and gets real work done across your apps, your files, your home and the web. Just ask.

Learn more and download at **[sense6.io/desktop](https://sense6.io/desktop)**.

This repository only holds the installers (see [Releases](../../releases/latest)); the app's source code is private.

## Opening it the first time

- **Mac:** open the installer and follow the steps. If macOS says it can’t check the app, open **System Settings → Privacy & Security** and click **Open Anyway**. The first time Sense6 starts, it asks for the permissions it needs and walks you through connecting your AI.
- **Windows:** if Windows shows “Windows protected your PC”, click **More info**, then **Run anyway**.
- **Linux:** make the AppImage executable (`chmod +x Sense6-Ai-linux-x64.AppImage`) and run it.

After that, new versions install themselves.
